# pc-checkup

A free Claude Code skill that checks a Windows PC the way a technician does: ask, back up, measure, check, fix, **prove**, report. Nothing changes before you approve the plan, every fix has an undo, and a restore point comes first.

## Install

Copy `skills/pc-checkup` into `~/.claude/skills/`, then type `/pc-checkup` in Claude Code.

## Use at your own risk

It runs admin commands on your PC (only after you click Yes). Read the plan before you approve it.
